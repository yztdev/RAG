# 派聪明测评集 v1 · 评测结果附件

教程里引用的 7 次评测，数据集是 [paismart-eval-v1.jsonl](../../../src/main/resources/eval/paismart-eval-v1.jsonl)（50 题），评测时间 2026-10-10 ~ 2026-10-11。

- 生成和评委模型都是 `deepseek/deepseek-v4-pro`；
- 检索：BM25 + KNN 双路召回，RRF 融合，gte-rerank-v2 重排序，topK = 5，父块扩展开启（命中分块前后各 1 块）；
- 知识库：派聪明介绍 PDF（96 个分块）、RustFS 实战知识卡（2 个分块）、一份 AI 应用开发简历（21 个分块），另有几份其他文档作为检索干扰项。

## 怎么读

1. **01 → 02**：阈值 0.2 时 8 道同义改写题全部返回 0 条。gte-rerank-v2 给口语化提问的正确分块只打 0.14~0.19 分，整批被阈值过滤（每条用例的 `rerankScores` 可以看到分数）。降到 0.1 后，Recall@5 从 56.5% 到 76.1%，评委准确率从 65.3% 到 86.0%。
2. **02 和 03 指标相同，但 0.1 仍在过滤噪声**：两者的 Recall 和 MRR 一样，说明 0.1 已经不再误杀正确结果；区别在于 0.1 会挡掉明显不相关的结果，比如两道 RustFS 题在 0.1 下只返回 2 条，阈值为 0 时会再塞进 3 条 0.06~0.09 分的无关分块。另外，无答案题在阈值 0 时也全部正确拒答，拒答靠的是提示词，不是阈值。
3. **文件级和分块级差了 24 个百分点**：知识库里一份 PDF 占了大部分分块，只按文件判断时召回任何一块都算对，Recall 虚高到 100%。只按文件标注时，有 5~7 道题被归因成“检索命中但答错”，换成分块级后它们全部变成“检索未命中”。
4. **04 有 3 条失败**：推理模型的思考过程也占输出 token，当时预算偏小，输出为空。05~07 加了空输出重试，失败为 0。
5. **05~07 三轮**：检索是确定性的，三轮检索指标完全一致；评委准确率三轮都是 86.0%，平均分在 4.32~4.42 之间波动。

## 文件内容

每个文件只含数字和用例 id，不含问题、回答、评委理由和检索到的原文：

- `config`：评测时的检索和模型配置；
- `originalSummary`：评测接口当时输出的汇总（01~04 的 `recallAtK` 是文件级口径）；
- `overall` / `byType`：按上面的统一口径重新汇总，`byType` 按题型拆分（fact / para / multi / conflict / rustfs / resume / neg）；
- `cases`：逐条用例的检索模式、召回条数、各条结果的 rerank 分数、分块级是否命中及排名、文件级是否命中、评委分数、是否答对、归因。

问题和参考答案在数据集文件里，按 `caseId` 对照即可。

## 评委人工校准（基于 05 这一轮）

从 50 题里按评委结论分层抽 15 道做人工复核，复核表见 [human-review-v1.md](../human-review-v1.md)：

- A 层：评委判错的 7 道全选；B 层：评委判对、但检索没召回答案分块的 4 道全选；C 层：其余 39 道评委判对的题随机抽 4 道；
- 复核用勾选版：把参考答案拆成要点（★ 为核心要点），人只勾“回答说到了哪些点”，判定和分数按固定规则从勾选结果算出来，评委打分不给复核人看。

| | 一致 | 说明 |
| --- | --- | --- |
| A 层 | 7/7 | 评委判错的题人也判错，评委没有判得过严 |
| B 层 | 1/4 | 3 道分歧都是评委判对、人判错：没检索到证据时，模型回答漏了核心要点，评委仍然放行 |
| C 层 | 4/4 | |
| 合计 | 12/15 | 一致率 80%，Cohen's kappa 0.61，评委分与人工分平均差 0.53 |

A、B 两层是定向挑的难题，这个一致率会比在全部题目上偏低；分歧集中在 B 层，说明评委在“检索没召回、模型凭别的片段作答”时偏宽松，这类用例的评委结论需要人工兜底。

同一批 15 道还让另一个 AI 按同样的标准代评了一遍（[cross-model-review-v1.md](../cross-model-review-v1.md)），三方对比：

| | 一致 | kappa |
| --- | --- | --- |
| DeepSeek 评委 vs 人工 | 12/15 | 0.61 |
| AI 交叉评审 vs 人工 | 13/15 | 0.73 |
| AI 交叉评审 vs DeepSeek 评委 | 14/15 | 0.87 |

两个模型之间的一致程度明显高于它们和人的一致程度：它们在同样的地方偏宽松，所以用一个模型去复核另一个模型，替代不了人工复核。
